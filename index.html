Como usar a lista

Para criar uma seção, abra Organizar seções, escreva o nome e clique em + Criar seção. A nova seção aparece na lista com o botão + para incluir produtos e fica salva no backup e no HTML atual. Digite o preço por unidade e ajuste a quantidade usando os botões − / + ou digitando. O subtotal é calculado automaticamente. Na Coca-Cola Zero 200 ml, cada fardinho tem 12 garrafinhas e o preço é informado por garrafinha. Toque no nome do produto para marcar como comprado. O botão + de cada seção adiciona um item à categoria. Em Organizar seções, altere a ordem usando as setas ou arrastando. A ordem e os novos itens são salvos automaticamente. A busca exibe apenas produtos cujo nome corresponde ao texto. Dois toques no total abrem a edição.

Exportação, backup e reinício

As alterações ficam salvas automaticamente neste navegador quando o armazenamento local está disponível. Salvar HTML atual baixa uma nova versão do aplicativo com todos os produtos, quantidades, preços, marcações, mercado e ordem das seções já incorporados. Ela funciona offline e pode ser aberta em outro aparelho, sem importar backup. Continue usando esse HTML salvo para novas alterações. O backup JSON permanece disponível como cópia de segurança.

Sobre o ES Lista

ES Lista | Versão 1.1

Lista de compras interativa com produtos por seção, quantidades, preços e totais da compra.

Como usar

  • Solicite seu acesso com um usuário de 4 letras ou números e senha de 4 números.
  • Aguarde a aprovação do administrador DUT8 e entre com a mesma conta nos seus aparelhos.
  • Edite preços e quantidades, marque os produtos no carrinho e acompanhe os totais.
  • Use Organizar seções para ajustar sua lista e as opções de backup para guardar uma cópia.

Salvamento e acesso

As alterações sincronizam automaticamente quando há conexão. Confira a mensagem de sincronização antes de fechar. Cada conta acessa sua própria lista; somente DUT8 pode liberar ou bloquear usuários.
